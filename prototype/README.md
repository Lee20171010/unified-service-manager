# HTML UI reference

The accepted interactive prototype is preserved under this directory, with an additional resource/plugin design reference under `next/`. It uses mock data only and does not contact managed hosts.

Serve only this directory for local review, for example:

```bash
python3 -m http.server 8080 --directory prototype --bind 127.0.0.1
```

Open http://127.0.0.1:8080. Production Web code is in `web/`.
